# 枪神快跑 | GUN GOD RUN
## 游戏简介
《枪神快跑》是一款**2D横版卷轴射击闯关**游戏，定位高机动性爽快动作射击。融合跑酷跳跃与射击玩法，强调动态操作、走位闪避与火力对抗，拥有关卡闯关、角色养成、皮肤收集、BOSS挑战等完整游戏体系。

## 一、游戏概述
### 基础定位
- 游戏类型：2D横版卷轴射击闯关
- 产品定位：中度核心向手游，高可玩性、支持重复游玩
- 核心亮点：跑酷射击融合、多主题关卡、角色成长、外观收集

### 故事背景
未来霓虹都市科技发达但秩序崩塌，**暗影军团**掌控生化士兵与机械体割据城市。玩家化身传奇雇佣兵「枪神」，深入沦陷区域，瓦解军团势力，揭开颠覆世界的幕后阴谋。

### 目标用户
- 受众年龄：16-35岁年轻玩家
- 兴趣偏好：喜爱快节奏动作、射击、平台跳跃；追求操作手感、排行榜竞技、道具皮肤收集

## 二、核心玩法
### 操作按键
- 移动：WASD
- 跳跃：K（空中可变相提升机动）
- 射击：J（自动瞄准）
- 技能：消耗MP释放
- 快捷键：L-打开仓库 | O/P-切换武器

### 战斗循环
1. 走位闪避：躲避弹幕与场景陷阱
2. 瞄准射击：枪械火力压制敌人
3. 技能穿插：清场小怪、自保突围
4. 资源管控：合理分配HP、MP消耗

### 角色状态属性
- **HP 生命值**：生存基础，归零时关卡失败；可拾取医疗包、使用回复技能恢复
- **MP 能量值**：释放技能必需；随时间自动恢复，拾取能量晶体可快速充能

### 底层核心逻辑
- `checkCollision()` 碰撞检测：判定子弹命中、陷阱扣血、敌人生死
- `createLevelData()/buildMap()` 关卡数据：定义地图结构、配置敌人/陷阱/道具掉落

## 三、角色系统
### 主角设定
代号：枪神
姓名：康神(Zmjjkk)
背景：前特种部队精英，退役独行雇佣兵，精通全枪械，拥有超强战斗直觉与动态视觉。

### 成长体系
- 等级升级：通关关卡、完成悬赏获取经验
- 自由加点：升级获得属性点，可分配HP、MP、移速、暴击伤害等

### 皮肤系统
- 风格：赛博朋克、铁血战士等多主题外观
- 获取方式：关卡奖励、商城兑换、限时活动
- 规则：仅视觉特效，不影响数值平衡；支持仓库收藏展示

## 四、关卡设计
### 章节结构
每章节包含 **3个普通递进关卡 + 终极BOSS关**
1. 幽邃地窟：深渊裂谷、索桥地形，对峙感拉满
2. 日落之城：地中海小镇，街巷紧凑、随机遭遇战斗
3. 莲花古城：密林神庙，含石门机关解谜
4. 隐士修所：复古修道院，回廊复杂，适合伏击对战

### 关卡元素
- 敌人：普通杂兵、高阶精英怪
- 场景互动：激光陷阱、掉落医疗包/能量晶体
- 通关目标：清空区域敌人、突破障碍抵达终点

### BOSS设定
- 身份：暗影军团改造型精英头目
- 技能：振奋提速、火力增伤、召唤伙伴、狂暴全属性强化
- 对战要点：拉扯走位、抓攻击后摇输出、大招可触发双倍伤害
